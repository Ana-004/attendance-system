# attendance-system
The  Attendance system which uses face recognition (DeepFace/PyTorch) to mark attendance in real time, with a local deployment handling scanning, recognition, and data storage via FastAPI, PostgreSQL.

A simple face recognition attendance system built using Python.

## Features

- Face detection and recognition
- Attendance tracking
- Python-based implementation
- Uses computer vision libraries
